# Market & Customer Segmentation Analysis

## Project Overview
This project groups customers based on their purchasing behavior using Machine Learning techniques.

## Dataset
Mall Customers Dataset

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-Learn

## Project Workflow
1. Data Preprocessing
2. Exploratory Data Analysis (EDA)
3. Customer Spending Analysis
4. PCA (Dimensionality Reduction)
5. K-Means Clustering
6. Visualization
7. Customer Segmentation

## Output
- Customer Clusters
- PCA Visualization
- Customer Segmentation Graphs

python main.py
